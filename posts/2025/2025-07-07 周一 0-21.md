# 前赘
停更了大概六个月。好吧，大概是一年。从高考结束后，我并没有进行连续的记录，所以借此机会，我想重新复盘~~（吐槽）~~下从高考后到现在的所见所闻及、所感所想。

# 续杯
## 游戏结束
高考确实是我高中考的最高的一次，五百六不到。当时很惊喜，但是听到友友们也都五八五九分超常时，七万名确实挺不入眼的。

接下来就是填志愿了。家里人和我都挺想去本地的乡村定向师范的，但很可惜，去年的分数刚好比我高一分，不用说，今年必然没机会。这点分，一本好专业没的看，二本随便填。

苏南的孩子想往南京考，苏北的孩子都想往苏南考。所以几个冲的学校，我都填了南京的。

虽然定向师范没了，但是如果能当个老师还是不错的，毕竟最香的饭，是公家饭。因此，稳的，我填了通大的师范。比去年高十多分，我还是挺有把握的。

最后便是保底的学校，至此怎么说都得好好放松一下了，想都没想，去了甜州的一所二本大学。

也许是，也许不是，天意。通大的那个专业组太干净了，三个全是师范，竞争激烈，这是当初没有想到了。好了，还是差一分。至此，我又和师范无缘。想着甜州大学还有直通车，我想想，算了，专业第一进来又怎么，大不了大二再去南京。

## 独立卫浴，上床下桌
就问你爱不爱吧：晚上断网不断电，瓷砖地，二十四小时供热水。虽然学校小且偏远，不让骑车，离地铁站和高铁站两公里，请假嘎嘎麻烦，上课念PPT，有许多老烟民 …… 但是又如何呢，我是来学习的，又不是来度假的，也许。说来也是运气巧，室友都是省内江南地区的，住的也相对比较近，而且都不抽烟，日常挺好相处的。

食堂有桃李梅三园，虽然放假时看抖音直播的学长说李好吃，但是我实际吃下来感觉李桃也都差不多，还更加偏向桃一点（尤其是放假的时候，李真的报吃）；至于梅，离得比较远，仅吃过几次，但足以让我 PASS。

这学期校园后面还新建了一个小公园，拖了很久，还是赶着合格性评估前开放的，给领导看罢了。有幸刚开放第二天就翘晚自习去看过了，夏天嘛，虫子比较多，不过造景还不错吧？说到晚自习，这种就是纯走形式，导员一个学期也就来一两次。

班长也是苦力，每次都要在学习通上发定位签到，不过我们的还是比较人性化的，距离宿舍刚好能签 (￣▽￣)"，，，扯远了。

## 实验室偶进
刚开学我就报了一个协会，还准备当学委。好消息，协会面试过了；坏消息，学委没吃上，但是上一段时间课后，感觉自由人真好。

开学不久我就申请了 Github 的学生认证，虽然过程漫长复杂，还拒了几次，但是最后还是成功申请上了。配合着 VSCode 用着，真香。

Quincy 也是协会里的，“表达能力” 比较强，在她一腔热血的邀请下，我们和另一个女生组了队报名了一个校赛。我们学校这个竞赛比较厉害，如果能进实验室来进一步培训是很不错的。

在这期间我收获不少，大多数学长学姐对我们我们这些小白非常友好，有啥不会的都会详细指导，这让我很有感触。最后运气不错，我们成功入驻了实验室，并且获取了一个工位。

在后续的培训中，大一的劣势就体现出来了：晚自习没时间、专业知识匮乏，导致进度远落后于大二的队伍。最后由于学校经费大量投入于石沉海底的一类 “PPT 大赛”，我们这个屡获佳绩的学科性二类竞赛经费严重不足，大一队伍最后没能参赛，比较可惜了。

我个人其实挺讨厌那些 “PPT大赛” （比如互联网+、挑战杯等等）， 祖传三代或者降维打击的项目，全是拼财力和关系。那种创新创业项目目前市场已接近饱和，真正能有独立的创新想法的项目非常少。与其在获奖希望渺茫的赛道上花费时间，不如去搞学科类竞赛，即使不能获奖也可以在过程中学到不少专业知识。

## 圈米杯 & 吸米子
大一上专业课就教了 C 语言，由于高中就浅学过 Python 和 JS，上手起来还是比较容易的。后来参加了学校的蓝桥杯软件校赛，运气不错卡线过了。

相对于电信院管理的电子赛道，物联网院的软件赛道经费感觉阔绰不少，只要过了校赛就给你统一报名（直接报销）；电子赛道则是拿了省二及以上才报销。刚开始还是用 C 打的，后来用了 C++ 之后才发现确实方便不少，STL 大法好。最后考前突击了一周~~（寒假在摆）~~，得了省一。

西门子杯的嵌入式赛项是今年新出的，一块简陋的巨型开发板要 200，避雷了。个别群管理心高气傲，问个问题不直接解答，反手就让你看公告，我看了三遍四五份 pdf 没一份提及相关问题。

期末周的开端并不是很友好。周六考四级，晚上七点出西门子赛题，周日座最早的高铁去南京考蓝桥杯国赛，然后周二开始考电路。

当然，最后两个竞赛的结果都不理想。蓝桥杯那天通勤时间没安排好，差点赶不上，过程中也没有状态，最后连个国优的没有。以前：我是废物（认命），现在：我是废物（自豪）？西门子截止那天状况频发，视频录得很短，被采样恶心到了。今天刚查分数，只有一个二等奖，感觉按评分细则漏给了好多 …… 泪目。


## 吃老本，软著喜加一
说说这个协会吧，氛围感还是不错的，并没有想象中的那么循规蹈矩、按部就班，平时事情不多，清闲，但是会有不少活动的消息，因此加入协会也是一个打破信息差的手段。

不得不说，我的 +1 还是挺 “厉害” 的，不管从哪方面来说，认证工作吃喝玩乐两不误。

之前开会的时候，听人介绍过他大一就发了三四篇软著，两个专利，比较厉害，他自己在开部会时也说过软著自己申请比较麻烦，建议找人代发。正巧我高中自己写了几个前端的功能性网页放在 Github 上，就打算用 NodeJS 做服务器并封装成应用程序，所以寒假里我问他软著代发，结果直接推我了一个全包的，269，包软件、相关文档 ……

现在，软著以及其他一些著作权已经逐渐失去它原本的意义，转而变成了资本谋财、学生谋名的工具。这是无法避免的，哪里有需求，哪里就有市场。

## 幼稚视角
实话实说，我是有点野心的，毕竟是亏分进来了。所以每次 +1 在群里招聘牛马，我都会力所能及的报名，争取给他留下一个好印象，继承他的位置。可是机会有时就是给更加想进步的人。

前几天刷到一句话：学生普遍排斥人情世故。我目前就是这样的想法。只是我忽略了后半句。

协会挺好的，我在里面见识到了形形色色的人。

## 就在这儿吧

上学期我还挺老实的，老老实实去上课，水课也就玩玩手机，基本上周周去图书馆泡。当时我把成绩看的有点重了，想着来都来了拿一些奖学金也好，最后期末松懈躺平，但居然还是专业第二，害，摆烂的人多。

学校图书馆不算大，不过校园小，够了。每天来自习备考的人还是络绎不绝，起晚了好位置基本都没了。开学不久我就借了一本高数参考书，还挺好用的，一直用到下学期。书上公式全给你整理到一块儿了，题目也挺多。感觉现在图书馆基本都变成了“自习室”，馆里的学生都是来自习的，而不是看书。但是，图书馆的氛围确实比教室好多了。

这学期过于休闲，水课基本都让室友代签，高数常常上一半就跑， 图书馆也只有期末去逛逛。但是期末事情又一堆，根本来不及。通宵！那是不可能的，但是也是每天两点睡，累了。最后出成绩，还没两个室友高。想来也是，能来这里的也不是脑子不好，而我也不聪明多少，只是高考时运气好点罢了。下学期再发力吧欸。

出成绩的后，我用油猴脚本爬了教务系统的详细成绩。因为我现代史只有 71 分（不喜欢这个老师 + 摆烂），估摸着平时分肯定没给多少，结果一看，97？期末 54 分，好的，是我太摆了，，，

刚放暑假时后，直通车的通知发下来。经过许多考量，我还是放弃了提交申请。

首先就是毕业证还是这里的，去那里说白了就是借读，而且过去了基本上就处于爹不亲妈不爱的状态。像我这种不想挺老师念 PPT 的人，到哪里学都一样，但是注意期末考试是和那里的统考然后抄送分数回来，所以难度会大很多，没必要折磨自己。

我是比较喜欢搞竞赛之类的，但是去那里基本上就比绩点往考研方向走了，因为大多学科竞赛都是禁止跨校组队的。我不太想考研，但是大环境下好像有不得不考研；考公的申论我也写不来，道路也激烈。目前来说还是比较迷茫的。但是不管如何，舒适圈呆久了，或许就不想离开了叭。
