# Intro
最近在开发服务器时用 Live Server 扩展实时渲染网页时局域网一直无法访问，这个问题开学就发现了，但是当时并没有在开发什么前端项目，所以就把它搁置一边。现在的项目涉及到局域网通信，开启 Live Server 防火墙端口局域网内的手机也无法访问电脑，之后我就去 Github 上看 Issue ，结果发现这个 repo 已经三年没有维护过了。现在 VSCode 官方推出了一个 Live Preview 扩展，那就玩一下吧。

# Experience
虽然可以在开放 VSCode TCP 协议的防火墙后被局域网内的设备访问，但是整体用下来感觉不如 LiveServer，主要是一下几点：

1. 没有使用本地 IP 作为HOST 的快捷设置
2. 关闭需要命令，不如直接点击状态栏的图标关闭方便
3. 要调整消抖延时 Preview Debounce Delay 值为 1000（默认为 100 ，单位：ms）

诶，延时不是越短越好吗？确实。但是，作为 scss 的重度使用者，就会发现一个非常憋屈的问题：每次改动后 scss 会被编译成 css ，如果延时太短，css 没被还没编译完成网页就更新了，导致每次更新完的网页都是用的上一次更新的 css 。

# End
说起来也巧，从高一开始自学前端、接触 VSCode、使用 Live Server 开始，不知不觉到现在已经三年了，而 Live Server 也在三年前停止了维护。

⌈ 能跑就不要动 ⌋

代码一样，扩展也一样。

现在，Live Preview 也是一个不错的选择。
