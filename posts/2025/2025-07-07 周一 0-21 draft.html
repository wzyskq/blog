续杯

实验室偶进

刚开学我就报了一个协会，还准备当学委。好消息，协会面试过了；坏消息，学委没吃上，但是上一段时间课后，感觉自由人真好。

开学不久我就申请了 Github 的学生认证，虽然过程漫长复杂，还拒了一次，但是最后还是成功申请上了。配合着 VSCode 用着，真香。

Quincy 也是协会里的，“表达能力” 比较强，在她一腔热血的画饼下，我们和另一个女生组了队报名了一个校赛。毕竟我们学校这个竞赛比较厉害，如果能进实验室来进一步培训是很不错的。

在这期间我收获不少，大多数学长学姐对我们我们这些小白非常友好，有啥不会的都会详细指导，这让我很有感触。Quincy 的文字功底很好，比较适合文档类工作，但是她编程基础非常薄弱，基本上不是摇人就是问 AI。同时她也非常“会说话”，别人问起来，没成果都能被她说成非常厉害的样子。或许，能说会道真的能成事儿？确实，对她自己来说。我一个朋友说话很直白，两个字评价：人精。

活大多是我干的，有时想代码呢，突然来一句干的怎么样了，血压瞬间就上来了。概括来说，就是非常浮躁。之前有一次调小车，还在调试呢，她直接抢过去玩，真就无语。而且她喜欢刨根问底，这按道理来说是好事，但是你给她讲了一半，她又“嗷~”了，感觉全懂了，可实际让她写，又是啥也不会，等于白讲。这还不是最要命的，没本事还爱发脾气也是无敌了。让她写一小部分的代码，写不出来，没事，让你休息一会，还对我发牢骚，无语。

好在，另一个女生还是很认真的，暗地里也花时间调试，遇到问题沟通起来很容易。最后运气不错，我们成功入驻了实验室，并且获取了一个工位。

吃老本，软著喜加一

协会吧平时事情不多，但是会有不少活动的消息，因此加入协会也是一个打破信息差的手段。

不得不说，我们部长 Fell 还是挺 “厉害” 的，不管从哪方面来说，认证工作吃喝玩乐两不误。但是后来我就心生厌意。

之前开会的时候，听人介绍过他大一就发了三四篇软著，两个专利，比较厉害，他自己在开部会时也说过软著自己申请比较麻烦，建议找人代发。正巧我高中自己写了几个前端的功能性网页放在 Github 上，就打算用 NodeJS 做服务器并封装成应用程序，所以寒假里我问他软著代发，结果直接推我了一个全包的，269，包软件、相关文档 ……

我当初没有具体问是否能代发而不是全包，但是我能猜到， Fell 的软著估计都不是自己写的，光通过他晒在朋友圈里那软著的抽象应用名就能看出来。后来我还是全靠自己搞文档材料，最终等了两个月不到就批下来了，著作权人是我自己。

但值得一提的是， Fell “写”的软著上的著作权人是学校，这点很意思。如果这个软件真是自己投入时间和精力码出来的，怎么可能随随便便就转让著作权人给学校？当然，这只是我的臆测，但是相信各位自有想法。

现在，软著，以及其他一些已经逐渐失去它原本的意义，转而变成了资本谋财、学生谋名的工具。这是无法避免的，哪里有需求，哪里就有市场。当然，得软著可不止这一种方法。

上个月在茶馆中听到学姐分享她的写软著经验：到 Github 上随便找开源的代码抄一抄，东拼西凑就出来了，反正又不管你软件能不能运行。说的没错，但是我自己是大概率不会交一个缝合废品上去的。

在遵守开源协议的情况下借鉴部分代码我觉得无可厚非，毕竟自己也花了时间来修改兼容，但交一堆垃圾上去我是真的过意不去。除非我真的走投无路了，但是那是我大概率会直接买。

幼稚视角

实话实说，我是有点野心的，毕竟是亏分进来了。所以每次 Fell 在群里招聘牛马，我都会力所能及的报名，争取给他留下一个好印象，继承他的位置。可是随着次数变多，我逐渐失望。

那一次，他在群里招人来统计，我也傻愣愣的私聊了。结果到那里了，他自己人影也不见，我足足等了五十多分钟，期间问过他要做什么，不回，后来快五点了，说清点上交的大创项目计划书。点就点吧，你倒是发我清单啊，又等，好的，可算发来了。

最让我气愤的是，他先和另一个来的女生 Jana 说了要做的事情。点完了，帮忙全部整理好，按顺序放架子上整理好，缺的还空出来了，拍了照片发过去，没有后话？？？不说谢谢，你哪怕发个 ok 我都能接受，结果就是不理人。

后来，他在群里说想要当 Fell 的人把课表发给他，我又傻兮兮的发过去，还说了一句麻烦了，结果又是杳无音讯？？？现在想想，笑笑，终究还是太年轻。后来我和朋友谈起这件事，他说，你当初应该给他发个红包，然后发我太想进步了。现在回想，确实有道理。

意识到被资本做局，还是偶然在朋友圈刷到的。

之前有一个和我一起干苦力的部员 Marc，突然发了一条说（已删），大意是，当部长的前摇就是守 3xx 吗（部门教室）？

看完这条盆友圈的我 be like：？？？，什么情况？？？内定好了？？

再后来，他又在一个同为我们部的女生的一条朋友圈下留言，Nora 部还是太超标了。好家伙，又定下来一个，无话可说了。确实，也许我趋炎附势、小嘴吐蜜的能力还有待加强，嗯。

补充一下，这个 Marc 也是搞抽象的，盆友圈隔几个小时就发一次，作为一个男生也是挺厉害的。话说他大一就去南京实习了，看来也是有说法的。

放暑假前，Fell 在群里推了一个三下乡的活动，大概就是在暑假里带小孩，进了群后发现是这个 Nora 带队，确认完名单后，她把计划表发在群里，又值得注意的是，表上没有她自己。结果，考完最后一门的那天她就回家了。这是我长这么大见过为数不多的带队人自己不参加活动的队长。

讲个笑话，这个活动当初是定在七月出就开始的，结果拖到七月末，许多人都走了，最后只展开了两次。第一次去了两个人，Jana 和另一个男生 Severo 。第二次去了五个人，多了两个女生。整个线下活动基本上都是 Jana 负责的，包括一些小道具购买。

最早时，Fell 在群里说过可以给小朋友买些小东西，然后找他报销。结果活动结束后，Fell 两手一摊发语音给 Jana 说，这种活动本来就是不能报销的，乐了。最后 Jana 只能群发回血，平均每人 14.65 元，一开始我觉得挺没戏的，因为 19 人的群实际去了 5 人，估摸着除了我们几个没人会付款，但最后也都付了。自然，最后结项书有所有人的名字。

这让我想到了在二手群中的花钱买实践证明 …… 嗯，没区别。啊不，这是“官方”的。

前几天 Nora 在群里说这个项目评上了学校“优秀团队”一等奖，现在三个先进个人还差一个（另外两个包是 Nora 和 Jana，我认可 Jana，但是 Nora 你根本不配，即使你是这个活动的负责人），目前有三个候选人，并分别给出了理由。

Severo （总共两次线下活动全部参与）

陈同学（中青校园，大学生云报）学校发表人数多

刘同学（志愿青年学刊）学校发表人数少

然后在群里说：@所有人 大家赶紧投一下，匿名制，后面注明了比较优秀的三位同学做了什么，注明的媒体都是国家级的，志愿青年学刊比较难投。

6，给哥们儿整笑了，Severo 我知道，下面两个是什么东西，发表期刊和这次社会实践有什么关系？？？

协会挺好的，我在里面见识到了形形色色的人。

壹

现在是20号的凌晨十二点三十三分，距离开稿过了十三天，不得不吐槽我拖拉的坏毛病。本文保留了许多带有强烈情绪化的词句，请理性看待。还要沉淀。完。

贰

部分补充内容已在原文中添加。

现在是10月2日，协会已完成轮换，老成员除了晋升的，其余的自动退部。Nora 当了部长， Marc 不详，估计高低也是个副部。

开学时 Fell 和 Nora 在群里问想去迎新和宣传的私聊，是的，那时候 Nora 已经内定部长了。我自然不会私聊他俩，即使这或许是我向上的唯一机会。

最后补充一个点吧，Fell 是富哥。

还记得我之前说过的他吃喝玩乐俩不误么，盆友圈里不是获奖证书就是嗨皮照片，什么夜钓，live house，和平饭店，西班牙旅游等等。很久之前给他的一条装13盆友圈点赞，当时没意识到有问题，后来在学长的慧眼下才发现他把 Linux 拼成了 Lunix，现在想想我还给他点赞，真招笑。

富哥真好。机器人买现成的后再调（普遍共识），PPT大赛的论文报告咸鱼代做（传闻，大概真），软著更是一步到位（我就把话说满）…… 最后在拿这些唬人的奖状证书丢给那些不知含金量只看数量的无知答辩评委，这不，国家奖学金不就到手了？

但这不是一个良性循环么？

我酸了（T_T）
