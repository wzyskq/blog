# 引子

很早之前就买了 JDY-31 蓝牙模块，但是一直放着吃灰。正巧最近调试单片机时 USB 转 TTL 模块不够用，就想着用蓝牙模块来替代。后面配置完后的实际体验还是很不错的。后来又向实验室申请了一份蓝牙模块，结果发下了的是 HC-05。

蓝牙模块分为主机、从机和主从一体三类，主从两者的区别就是，主机可以主动连接其他蓝牙，但是从机不能主动连接其他蓝牙。JDY 只能是从机，而实验室发的 HC 为主从一体，这两者配置过程还是有些不同的，网上教程感觉部分稍有问题，故在此记录。

# JDY-31

## Features

JDY-31 有六个引脚：

| 引脚    | 描述                      |
| ----- | ----------------------- |
| STATE | 状态引脚（未连接设备为低电平，连接后为高电平） |
| RXD   | 输入引脚                    |
| TXD   | 输出引脚                    |
| GND   | 电源地                     |
| VCC   | 电源（3.6 ~ 6 V）           |
| EN    | 空                       |

一般来说 JDY-31 只需要接四根线，VCC、GND、RX、TX，其中 VCC 直接接 5V 就行。默认 JDY-31 串口配置如下表，串口调试助手也要一致。

| 选项   | 描述 |
| ------ | ---- |
| 波特率 | 9600 |
| 校验位 | 无   |
| 数据位 | 8    |
| 停止位 | 1    |

然后通过 USB 转 TTL 模块连接到电脑上，直接通过发送 AT 命令来配置。但要注意一些细节：

1. 只有在**未连接**的状态下才会处理 AT 命令，`AT+DISC` 断开连接命令除外。
2. 发送 / 接收格式都为 **ASCII 模式**
3. 要勾选**发送新行**，或者直接在发送数据末尾加上`\r\n`（注意是反斜杠）
4. 波特率的参数不用传统的 9600、38400、115200 等具体数字表示，而是用**数字 4 ~ 9** 来表示
    - 4：9600
    - 5：19200
    - 6：38400
    - 7：57600
    - 8：115200
    - 9：128000
5. `STATE` 引脚输出状态由 `AT+ENLOG` 的值控制，1 为开启，0 为关闭。默认开启。一般来说商家都会把 `STATE` 引脚连接到 LED 上，如果 `AT+ENLOG` 为 0，那么 LED 指示灯就不会闪烁了，所以**建议开启**。

## AT Command Sets

常见 AT 指令集，虽然不多，但是配置完就可以用了。

| 命令           | 描述           | 参考返回             | 参考默认值      | 发送样例         |
| -------------- | -------------- | -------------------- | --------------- | ---------------- |
| `AT+VERSION`   | 版本号         | +VERSION=JDY-31-V1.35| JDY-31-V1.3     | /                |
| `AT+NAME`      | 蓝牙名查询     | +NAME=JDY-31-SPP     | JDY-31-SPP      | /                |
| `AT+NAME<Param>`| 蓝牙名设置    | +OK                  | /               | AT+NAMECAT       |
| `AT+PIN`       | 连接密码查询   | +PIN=1234            | 1234            | /                |
| `AT+PIN<Param>`| 连接密码设置   | +OK                  | /               | AT+PIN8888       |
| `AT+BAUD`      | 波特率查询     | +BAUD=4              | 4（9600）       | /                |
| `AT+BAUD`      | 波特率设置     | +OK                  | /               | AT+BAUD8         |
| `AT+ENLOG`     | 输出状态查询   | +ENLOG               | 1（开启）       | /                |
| `AT+ENLOG<Param>`| 输出状态设置 | +ENLOG=1             | /               | AT+ENLOG0        |
| `AT+DISC`      | 断开当前连接   | +OK                  | /               | /                |
| `AT+DEFAULT`   | 恢复出厂设置   | +OK                  | /               | /                |

# HC-05

## Features

先说结论：HC-05 引脚与 JDY-31 一致，但若要进入 AT 配置模式，须提前让使能端 `EN`上电（**按住按键，上电后松手**）。**部分机型**（比如说实验室里发的这块）每次发送完一次 AT 指令，需要**按下按键重置**，然后再继续发送想要的配置项。

当初我看了一篇阿里云开发者社区的[文章](https://developer.aliyun.com/article/1074226#:~:text=进入命令响应工作模式有两种方法)，原文如下：

>**进入命令响应工作模式有两种方法：**
>
>- 模块上电，未配对情况下就是AT模式，波特率为模块本身的波特率，默认：9600，发送一次AT指令时需要置高一次PIO11；
>- PIO11 置高电平后，再给模块上电，此时模块进入AT 模式，波特率固定为：38400，可以直接发送AT指令。
>
>什么叫做置高一次PIO11？
>
>在蓝牙模块中有一个小按键，按一下就置高一次PIO11。也就是说，第一种方法需要每发送一次AT指令按一次；而第二种方式是长按的过程中上电，之后就无需再管了，直接发送AT命令即可。
>
>需要注意一下，两种进入命令响应工作模式的方式使用的波特率是不一样的，建议使用第二种方式。
>
>**怎么区分进了命令响应工作模式呢？**
>
>在蓝牙模块上有灯，当灯快闪的时候，就是自动连接工作模式；当灯慢闪的时候，就是命令响应工作模式，当灯慢闪两下的时候就是与手机正常连接模式。

而我遇到的情况是，需要先按住按键上电后松手，然后才进入命令响应模式（慢闪），否则就是自动配对模式（快闪）；当我在命令响应模式下发送完第一条指令并收到回复后，再发送指令就无效，除非再按一下按键，然后重复此操作来进行配置。

总结一下，操作过程的注意事项大部分与上文一致，但是也有小部分不同：

1. AT 模式下波特率**固定为 38400**，其他串口配置与 JDY 初始状态一致。连接模式下都和 JDY 初始状态一致。
2. 波特率参数为真实数据，如 115200 等等，具体看下面的 AT 命令操作。

## AT Command Sets

相比 JDY 的指令集，我更喜欢 HC-05 的，主要是在通过 `=` 来区分命令类型，挺喜欢这点的。

| 命令                                 | 描述           | 参考返回           | 参考默认值 | 发送样例             |
| ------------------ | -------------- | ------------------ | ---------- | -------------------- |
| `AT`                                | 测试指令       | OK                 | /          | /                    |
| `AT+NAME?`                          | 蓝牙名查询     | +NAME:HC-05        | HC-05      | /                    |
| `AT+NAME=<Param>`                   | 蓝牙名设置     | OK                 | /          | AT+NAME=DOG          |
| `AT+PSWD?`                          | 连接密码查询   | +PSWD:1234         | 1234       | /                    |
| `AT+PSWD=<Param>`                   | 连接密码设置   | OK                 | /          | AT+PSWD=8888         |
| `AT+UART?`                          | 波特率查询     | +UART:9600,0,0     | 9600       | /                    |
| `AT+UART=<Param1>,<Param2>,<Param3>`| 波特率设置     | OK                 | /          | AT+UART=115200,0,0   |
| `AT+ROLE?`                          | 主从状态查询   | +ROLE:0            | 0（从机）  | /                    |
| `AT+ROLE=<Param>`                   | 主从状态设置   | OK                 | /          | AT+ROLE=0            |
| `AT+RESET`                          | 退出配置模式   | OK                 | /          | /                    |
| `AT+ORGL`                           | 恢复出厂设置   | OK                 | /          | /                    |

需要注意的是 `AT+UART?` 有三个返回值，一般来说后两位不用改，具体如下表：

| 参数           | 值                                                                 |
| ----------------- | ----------------------------------------------- |
| `Param1`：波特率 | 4800、9600、19200、38400、57600、115200、230400、460800、921600、1382400 |
| `Param2`：停止位 | `0`：1 位；`1`：2 位                                              |
| `Param3`：校验位 | `0`：无（None）；`1`：奇（Odd）；`2`：偶（Even）                  |

除了默认的从机模式外，我拿到的主从一体 HC-05 还支持主机模式和回环模式，配置参数如下表：

| 参数         | 模式                         |
| ------------ | ---------------------------- |
| `AT+ROLE=0`  | 从机模式（Slave）            |
| `AT+ROLE=1`  | 主机模式（Master）           |
| `AT+ROLE=2`  | 回环模式（Loopback，即将数据原路返回） |
